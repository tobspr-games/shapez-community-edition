# 10. 단계별 로드맵과 완료 조건

모든 단계는 **작게 분리된 PR/커밋**, 읽을 수 있는 테스트 결과, 롤백 가능한 변경으로 구성한다.

## M0. 저장소 및 Codex 환경 부트스트랩

**목표:** CE가 이 저장소에서 설치·빌드 가능한지 확인.

- 업스트림 커밋 기록, 의존성·Node 버전·라이선스·빌드 명령 검증.
- Codex Cloud `df -h`, `du -sh`로 실제 작업 공간 측정.
- CI의 최소 정적 검사/컴파일 단계 확인.
- 저장소 기본 `README`, `AGENTS.md`, 이 문서 세트 적용.

**완료 조건:** 재현 가능한 설치·검증 명령과 환경 제약 보고서. 게임 로직 변경 없음.

## M1. 레거시 데이터 모델 및 분석기 (읽기 전용)

- 기존 `.bin` 디코더/검증 구현, 샘플 버전 지원.
- 엔티티/모드 건물/허브/벨트/인플라이트 아이템 통계 리포트.
- 숫자 건물 코드와 모드 문자열 ID를 정확한 레지스트리로 매핑.
- 개인정보 제외한 작은 픽스처 구축.

**완료 조건:** 개인 파일의 복사본을 *수정 없이* 파싱; [09](09-save-baseline.md) 통계 재현 또는 차이 이유 분석.

## M2. CE 기반 모드 기능 유지 + 세이브 변환

- 미러 건물, Micro Hub의 레거시 ID 어댑터.
- 모드 5종의 CE에서의 실제 작동/장애 목록.
- 원본 `.bin` → 신규 버전 저장 구조로 단방향 변환.
- 누락 엔티티/벨트 아이템/회로 필드 보고서, 별도 저장 슬롯 작성.

**완료 조건:** 기존 유저 공장을 로드하고, 저장-재실행 후 주요 공정이 이어지는지 확인. 원본 보존.

## M3. Snippet Library MVP

- 선택 영역 저장, 라이브러리 영속화, 검색, 미리보기, 회전/반전 설치.
- 다른 세이브로 모듈 이동, 연구/배치 비용 검증.

**완료 조건:** 3가지 실사용 모듈을 저장/불러온 후 입출력 설정이 유지됨.

## M4. 성능 기준선 및 편의 기능 개선

- TPS/FPS/시스템별 시간 측정.
- 비차단 Shape finder, 통합 Speed Control, 반전 구조 공통화.
- 기존 대형 세이브에서 빌드별 성능·정확성 비교.

**완료 조건:** 주요 병목 수치화, 전후 결과 리포트 및 회귀 테스트.

## M5. 새 물류 시스템

- 1×1 교차로 → 4방향 라우터 → 채널형 텔레포터 → 패킷 운송 순서로 단계화.
- 각 기능별 무손실/무복제/버퍼 정합성/모드·Snippet 연동 검증.

**완료 조건:** 주요 경계 조건 테스트와 세이브 왕복 검증.

## M6. 산업 전력 및 오버클럭

- 발전기 6티어와 지정 연료 조합/해금.
- 발전 버퍼, 전력망 연결/배전 범위/축전지/우선순위.
- 기존 설비 선택적 2배 오버클럭, 벨트 속도 경계 처리.

**완료 조건:** T1~T6 발전이 의도대로 작동, 기본 공장 무전력 동작 유지, 오버클럭 중 도형 보존/전력 계산 일치.

## M7. 선택적 네이티브 엔진 실험

- 측정된 병목 모듈 1개에 대한 C++20 + Emscripten/Wasm 대체 실험.
- JS/TS와 처리 정확도·성능·통신 비용 비교.
- **좋아질 때만 도입**. 무리한 전체 재작성 금지.

**완료 조건:** 프로토타입과 실측 리포트; 프로젝트 채택/보류 결정 기록.

## 공통 테스트 매트릭스

| 종류 | 테스트 내용 |
| --- | --- |
| 세이브 | 구형/신형 저장-불러오기, 실패 롤백, 중간 아이템 보존 |
| 건물 | 0/90/180/270° 회전, 반전, 인접 입력/출력, 배치 충돌 |
| 물류 | 채널 변경, 포화/역압, 동시 입력, 합류, 끊긴 네트워크 |
| 전력 | 연료 부족, 배전탑 중첩, 전력망 분리, 축전지 0/100% |
| 오버클럭 | 1×→2×→1×, 벨트 경계, 부분 전력 부족, 회로 제어 |
| Snippet | 저장-재기동-재배치, 누락 모드, 미해금/비용 부족 |
| 성능 | 60TPS 중심 평균/p95/p99, CPU·메모리, 생산량 비교 |

## 변경 승인 시 제출할 리포트

1. 목적과 변경 파일.
2. 정확성/세이브 영향과 마이그레이션 필요 여부.
3. 실행한 테스트와 결과.
4. 성능 영향(측정했으면 수치, 미측정이면 미측정 표시).
5. 남은 위험/모호한 요구사항.
