# 01. 프로젝트 비전과 범위

## 한 줄 목표

**Shapez 1의 핵심 재미(도형 자동화)는 유지하면서, 더 큰 공장을 효율적으로 시뮬레이션하고 새로운 물류·전력·회로·공장 재사용 체계를 제공하는 독립 확장판을 만든다.**

- 저장소 이름: `shapez-CE-industrial-reengineering`
- 작업 기반: Shapez Community Edition(CE) 독립 Fork
- 공식 Shapez 1: 기존 동작·모드·세이브를 비교하기 위한 참조 구현
- 목표 대상: 데스크톱(Electron)을 우선 지원. 웹 빌드는 초기 목표가 아니다.

## 사용자 중심 목표

1. **[확정] 기존에 제작한 공장을 최대한 이어서 플레이한다.** 기존 `.bin`을 새 저장 형식으로 *변환*해도 괜찮으며 원본과 100% 동일한 내부 표현까지 요구하지 않는다.
2. **[확정] 기존 사용 모드 5종의 핵심 기능을 통합한다.** 도형 검색, 이동식 허브, 텔레포터, 게임 속도 조절, 건물 좌우 반전.
3. **[확정] 우수한 공장 설계 부분을 Snippet으로 저장하고 언제든 재사용한다.** 게임 세이브와 별도의 라이브러리가 이상적이다.
4. **[확정] 6단계 발전기**를 구현하고, 미리 정의한 도형을 연료로 사용한다. 티어별 *서로 다른 동시 필수 연료 종류 수*는 `1 / 1 / 2 / 3 / 4 / 6`이다.
5. **[확정] 최종 T6 발전기는 준무한 전력**을 제공하여 달성자에게 샌드박스에 가까운 보상이 된다.
6. **[확정] 전력 여유를 활용한 2배 오버클럭**을 도입한다. 기존 가공기와 벨트 등에 적용할 수 있어야 하며, 중·후반에나 실용적으로 쓸 수 있도록 전력 요구량을 높인다.
7. **[합의된 방향] 1×1 교차로, 전방향 고급 분배기, 묶음 운송, 회로 기반 텔레포터**를 추가한다.
8. **[합의된 방향] 더 큰 공장에서 FPS/TPS를 유지**하는 것이 중요한 설계 목표다.

## 설계 철학

- **산업 자동화 중심**: 복잡도를 위한 복잡도보다 실제 공장 운영과 최적화에 의미를 부여한다.
- **진입장벽 억제**: 기존 기본 생산 설비는 무전력으로 작동한다. 새 전력 경제는 고급 설비와 오버클럭 중심.
- **의미 있는 최종 보상**: T6는 반드시 극한의 연료 공장 건설을 요구하지만, 달성 후 전력 부족 걱정을 최소화한다.
- **성능 우선**: 60 TPS를 포함한 사용자 선택 시뮬레이션 설정에서 대형 공장을 대상으로 실측한다. 모니터 주사율과 TPS는 구분한다.
- **데이터 보존**: 변환 중 손실 가능성은 항상 사용자에게 보고하고 원본을 보존한다.

## 초기 범위 밖 (비목표)

- 첫 릴리스에서 원본 게임/모든 커뮤니티 모드의 완전한 호환성 보장.
- C++ 전체 엔진을 한 번에 교체하는 빅뱅 리라이트.
- 현실적인 전압·저항·주파수·송전 손실 시뮬레이션.
- 다른 플레이어와의 멀티플레이, 서버 호스팅, 온라인 Snippet 서비스.
- 전력 배전탑을 겹쳐 배율을 무한히 올리는 시스템.

## 성공 판정

- 기존 대형 세이브의 원본 복사본이 손상되지 않는다.
- 이전 도구가 원본 건물/진행도/모드별 매핑 결과를 보고하고, 변환 후 게임에서 주요 공장을 이어서 운영할 수 있다.
- Snippet을 저장하고 다른 세이브에서 복원하여 같은 공장 기능을 재현할 수 있다.
- 전력·연료 소비·오버클럭과 물류에서 도형 복제/손실이 발생하지 않는다.
- 동일 조건의 대형 벤치마크에서 변경 전후 처리 시간 및 정상 생산량을 수치로 비교할 수 있다.
