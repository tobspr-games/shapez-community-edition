# 09. 실제 제공된 원본 세이브 — 읽기 전용 분석 기준

## 출처 및 검증 단계

- 출처: 사용자가 제공한 Shapez 1 `.bin` 세이브(개인 파일; 공개 Git에 포함하지 않음).
- 이전 대화에서 바이너리를 읽기 전용으로 디코딩해 JSON 및 요약 보고서를 생성했다.
- 파일 형식 추론과 통계는 **원본 데이터를 디코딩한 분석 결과**이며, CE에서 실제 로드/저장에 성공한 기록은 아니다.
- 이 문서는 **계획·변환 검증용 메트릭**이다. 코드나 이 ZIP에 원본 세이브 전체가 들어 있다는 뜻이 아니다.

## 마이그레이션 기준선

다음 메트릭을 변환 전후 자동 비교한다.

- 엔티티 수 및 미해결/변환된 건물 건수.
- 미러 건물의 **위치·회전·입출력 슬롯** 기능적 일치.
- Micro Hub 11개의 중앙 허브 납품 기능 유지.
- 허브 레벨 26, 업그레이드 8/7/7/8, 저장 도형 42종과 수량.
- 운송 중 도형 수 110,038개를 변환 후 어떻게 처리했는지 상세 보고.
- 15개 웨이포인트, 가능하면 카메라 상태 복구.

**정확한 아이템 수 동등성은 새 물류 구조로 변환하기 어렵다면 예외를 보고할 수 있지만, 조용한 손실은 불가.**

## 성능 기준선으로 활용할 때

원본 세이브는 맵 규모가 큰 스트레스 테스트 입력이다. 재현 가능한 비교를 위해 저장 시점, 카메라 위치, TPS, 모드, GPU 드라이버 및 빌드 버전을 기록한다. 원본 파일로 곧장 벤치마크를 반복하며 덮어쓰지 말고 별도 복사본을 사용한다.

**절대 공개 저장소에 포함하지 말 것:** 실제 `.bin`, 전체 디코딩 `.json`, 유저 개인의 웨이포인트 이름/좌표 등이 담긴 덤프, 자동 생성 화면 캡처(별도 공개 동의 없는 경우).
